# proofback for VS Code

Shows reviewer feedback imported with [proofback](https://github.com/Amet13/proofback)
on the exact lines of your LaTeX sources.

- **Review feedback** view in the Explorer, grouped by file.
- Highlights on the anchored text, with the reviewer's note on hover.
- Mark items done, won't fix or discuss; reply; apply suggested edits after
  previewing the diff.

Requires the `proofback` command (set `proofback.path` if it is not on your PATH)
and a project initialised with `proofback init`.
